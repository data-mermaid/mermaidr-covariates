# Get covariate type

Tells you covariate type (raster, vector, raster and vectors, or
unknown)

## Usage

``` r
get_covariate_type(covariate)
```

## Arguments

- covariate:

  Covariate name or ID

## Examples

``` r
# get_covariate_type("Daily Global 5km Satellite Sea Surface Temperature (CoralTemp)")
# get_covariate_type("GPW MEOW Realms")
```
